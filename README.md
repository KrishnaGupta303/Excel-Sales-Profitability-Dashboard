# Sales Analytics Dashboard

## Project Overview
This project presents an interactive Excel Sales Analytics Dashboard developed to analyze Adventure Club's sales performance, profitability, and regional business performance.

The dashboard uses Pivot Tables, Pivot Charts, KPI cards, and interactive Slicers to make business insights easier to understand.

## Dashboard Preview

![Dashboard](Images/dashboard_preview.png)

## Key Performance Indicators (KPIs)
- Total Revenue
- Total Profit
- Gross Margin Profit
- Total Units Sold
- Total Orders
- Cost of Goods Sold (COGS)

## Dashboard Features

1. **Monthly Revenue & Profit:** Tracks monthly revenue and gross profit.
2. **Top 5 Countries by Revenue:** Identifies the highest-performing countries.
3. **Revenue Share by Channel:** Compares Corporate, Marketplace, Online Store, and Retail Partners.
4. **Region-wise Comparison:** Analyzes sales performance across different regions.
5. **Country-wise Map Chart:** Displays geographical sales performance.
6. **Interactive Slicers:** Filters dashboard data by Product Category, Country, and Quarter.
